Claude Code 2.0 na prática

O que cada novidade faz, como ligar e um prompt pronto para copiar. Sem programar.

Em resumo

Este guia mostra, em linguagem simples, as 13 novidades mais úteis do Claude Code, o assistente da Anthropic que trabalha nos seus arquivos e no seu computador. É para quem cria conteúdo, ensina ou toca um negócio e quer usar a IA no dia a dia sem saber programar. Cada novidade traz o que ela resolve, onde ligar, um cuidado e um prompt pronto para colar. Para usar, basta o app do Claude no Mac ou no Windows e um plano pago (Pro, Max ou Ultra); algumas novidades ainda estão em teste ou só nos EUA, e o guia avisa em cada uma.

O que é

Uma página para consultar, testar e compartilhar

"Claude Code 2.0" é o apelido que muita gente deu ao pacote de novidades das versões 2.1.x do Claude Code (não é o antigo modelo Claude 2). Aqui está o que mudou, conferido na documentação oficial em 1º de novembro de 2026.

🎯 Uma novidade por vez

Cada cartão tem o problema que resolve, os passos para ligar e o que evitar. Você testa uma, depois a próxima.

📋 Prompt pronto

Todo cartão termina com um prompt de exemplo. Clique em Copiar, cole no Claude e troque os nomes pelos seus.

🧾 Só o que é oficial

Nomes e atalhos conferidos na documentação. O que está em teste, pago à parte ou fora do Brasil vem avisado.

Antes de começar

O que você precisa

Três conferências rápidas evitam a maior parte das dúvidas.

1. O app do Claude

As novidades da aba Code ficam no app do Claude para Mac e Windows (baixe em claude.com/download). Quase tudo aqui se faz no app, sem terminal. No Linux, o caminho é o Claude Code no terminal.

2. Um plano pago

Pro, Max ou Ultra. Algumas novidades (Projects, Claude Duet) ainda pedem lista de espera; o Motion só aparece nos planos Team e Enterprise.

3. App atualizado

Muita coisa depende da versão. Instale a atualização sempre que o app oferecer. Opcional, para quem já usa o terminal: o comando abaixo mostra a versão do Claude Code (os mods pedem 2.1.287 ou mais).

claude --version

Palavras deste guia

Sessão: uma conversa do Claude com o seu próprio histórico. Contexto: tudo o que o Claude está levando em conta naquela conversa. Thread: uma tarefa dentro de um projeto, com a sua própria conversa. Skill: um pacote de instruções que você ensina ao Claude e chama pelo nome. Prévia e beta: recursos ainda em teste, que podem mudar ou ainda não estar liberados para todos. Terminal: a janela de comandos do computador; aqui ele é opcional. Prompt: o texto que você cola na caixa de mensagem do Claude. Minutagem: o ponto do vídeo em minutos e segundos (ex.: 02:15). Ultra: o plano pago mais alto do Claude, acima do Max. VS Code: um editor de código; só interessa a quem programa. Team e Enterprise: planos de empresa, pagos por equipe.

Atalhos: onde o guia diz Cmd (Mac), no Windows use Ctrl; onde diz Option, use Alt.

As 13 novidades

Escolha uma e teste agora

Clique para ir direto ao cartão. Os exemplos usam o dia a dia de quem cria um curso, um vídeo ou um post. O cartão 1 cria a pasta aula-1 com o roteiro aula-1/roteiro.md, que os outros prompts usam; se preferir, troque esse caminho pelo nome de um arquivo seu.

01

Seções por projeto

Tudo de um trabalho num lugar só: conversas, arquivos e tarefas.

Na aba Code do app, as conversas agora ficam em seções na barra lateral. Em vez de uma lista enorme, cada projeto (um curso, um canal, um cliente) ganha a sua seção, e você encontra tudo sem rolar.

Como usar

  1. Atualize o app e abra a aba Code (no topo do app, ao lado de Chat).
  2. Ao abrir uma sessão nova, escolha a pasta do projeto no seu computador. Se não achar onde, pergunte ao próprio Claude: "como abro uma sessão na minha pasta Documentos/curso?". A barra lateral mostra as conversas agrupadas em seções.
  3. Use uma seção por projeto. Antes, essas seções se chamavam "grupos".

Dica

Pense nos 5 trabalhos que você tem hoje. Uma seção para cada um basta.

✕ Evite
Deixar todas as conversas numa lista só.
✓ Faça
Uma seção por projeto.
Organize esta pasta para o meu curso "Planilhas com IA".
Crie uma lista de tarefas desta semana: roteiro da aula 1 (salve em aula-1/roteiro.md), 5 exercícios e 1 post de divulgação.
Vá marcando cada item quando terminar.
Salve tudo numa pasta chamada "aula-1".
Pergunte antes de mudar ou apagar qualquer arquivo que já esteja aqui.
02

Side chat

Pergunte do lado. A conversa principal continua limpa.

Uma dúvida rápida no meio do trabalho não precisa entrar na conversa principal. O side chat responde com o que o Claude já sabe daquela sessão, e essa troca fica de fora do histórico principal. A conversa principal fica menor e mais rápida.

Como usar

  1. No app: Cmd + ; (Windows: Ctrl + ;) abre o side chat; cole a pergunta abaixo.
  2. No terminal: digite /btw e a pergunta.
  3. Feche e volte ao trabalho.

Quando usar

Qualquer pergunta rápida: um sinônimo, uma conta, "o que é isso?". A conversa principal fica para o trabalho.

✕ Evite
Encher a conversa principal de perguntas soltas.
✓ Faça
Abra o side chat e pergunte do lado.
Qual é um sinônimo curto para "impressionante" que funcione num título de vídeo?
03

Split view

Duas conversas lado a lado, cada uma com o seu trabalho.

Você acompanha duas sessões ao mesmo tempo na mesma janela. Uma escreve o roteiro, a outra prepara o post. Cada uma segue no seu ritmo e você vê as duas.

Como usar

  1. Option + clique (Windows: Alt + clique) numa sessão da barra lateral.
  2. Ou botão direito na sessão → Open in → Split view.
  3. Para tirar do split: Cmd + Ctrl + W (Windows: Ctrl + Alt + W).

O que pôr lado a lado

Dois trabalhos diferentes. Nunca as duas sessões mexendo no mesmo arquivo.

✕ Evite
As duas sessões editando o mesmo arquivo.
✓ Faça
Um trabalho para cada lado.
Escreva o post da comunidade desta semana a partir do roteiro em aula-1/roteiro.md.
120 palavras, palavras simples, e uma pergunta no fim para as pessoas responderem.
Não publique. Me mostre o rascunho.
04

Ajudantes (subagentes)

Uma conversa divide o trabalho entre ajudantes e junta o resultado.

Você entrega um trabalho grande para uma conversa. Ela abre ajudantes (subagentes), cada um faz uma parte no próprio contexto e devolve um resumo. A conversa principal confere e junta tudo. Muita gente chama isso de "sessões aninhadas", mas o nome oficial é subagente.

Como usar

  1. Abra uma sessão na pasta do projeto.
  2. Dê o trabalho inteiro, dividido em partes.
  3. Peça um ajudante por parte e uma conferência no fim.

Gasta mais?

Sim. Cada ajudante consome do seu limite. Comece com 2 ou 3. Para coordenar várias sessões de verdade, veja o curso Claude como gestor de agentes.

✕ Evite
Abrir 20 ajudantes e sair.
✓ Faça
Comece com 2 ou 3 e olhe o consumo.
Transforme a aula 1 (aula-1/roteiro.md) em:
1. Um resumo da aula
2. 5 ideias de cortes curtos com a minutagem
3. 3 posts curtos para redes sociais
4. Um post para a comunidade
Use um subagente para cada item. Cada um faz só a sua parte e devolve o resultado.
No fim, confira os quatro, corrija o que não bater e me dê um resumo curto.
05

Computer use em segundo plano

O Claude usa os apps do seu computador enquanto você continua trabalhando.

Para programas sem outro jeito de automatizar, o Claude clica e digita sozinho dentro do app. No Mac, isso acontece em segundo plano, sem tomar o seu mouse. No Windows, não mexa no mouse nem no teclado enquanto ele trabalha.

Como usar

  1. Ligue o computer use nas configurações do app (Settings); ele vem desligado.
  2. No Mac, libere Acessibilidade e Gravação de Tela. No Windows, aceite o que o app pedir.
  3. Peça um trabalho dentro de um app.

Ideias de uso

Exportar um vídeo num editor, organizar prints por mês, testar todos os botões de um app que você criou.

✕ Evite
Liberar todo app que ele pedir.
✓ Faça
Libere só o app daquele trabalho.
Está em teste (prévia de pesquisa) no Mac e no Windows, nos planos Pro, Max e Ultra. Não vale para Team e Enterprise. Navegadores ficam só para ver: em sites, o Claude usa o navegador embutido dele (novidade 8).
Use o computer use (no Mac, em segundo plano, sem tomar a minha tela).
Organize os prints que estão na minha Área de Trabalho em uma pasta por mês, dentro de "Prints".
Não apague nada.
Me avise quando terminar e quantos arquivos você moveu.
06

Projects na nuvem

O trabalho continua com o notebook fechado.

O novo Projects é uma conversa contínua em que o Claude abre uma thread para cada tarefa. As threads rodam na nuvem, então a pesquisa segue mesmo com o seu computador desligado. Ele avisa quando uma thread precisa de você. Não confunda com o Projects antigo do claude.ai, que era uma pasta de arquivos.

Como usar

  1. Procure Projects na barra lateral (claude.ai/code ou aba Code do app).
  2. Não aparece? Entre na lista de espera.
  3. Abra um projeto e peça as tarefas.

Seus arquivos

O que vai para a nuvem sai do seu computador. Decida antes o que pode subir.

✕ Evite
Subir arquivo sigiloso de cliente.
✓ Faça
Deixe o que é privado numa pasta local.
Beta com lista de espera, nos planos Pro, Max e Ultra.
Pesquise o que mudou nas ferramentas de IA para criar vídeo nos últimos 30 dias.
Liste 5 novidades, com o link da fonte de cada uma.
Depois escreva 3 ideias de título para um vídeo sobre isso, cada uma com menos de 60 caracteres.
Salve tudo em pesquisa.md.
07

Remote Control

Acompanhe e aprove pelo celular. O computador continua trabalhando.

Você deixa uma sessão rodando no computador e acompanha pelo celular, no app do Claude. Lê o plano, aprova e sai. Não precisa de terminal no celular.

Como usar

  1. Na sessão, digite /remote-control (ou /rc), na caixa de mensagem da sessão. No app, também dá para ligar no cartão Environment (ambiente) da sessão.
  2. Em Settings → Code (configurações), ligue "Keep this computer awake for Remote Control" (manter o computador acordado).
  3. No celular, abra o app do Claude com a mesma conta e entre na sessão.

Lembre

O trabalho roda no seu computador. Se ele dormir ou desligar, para.

✕ Evite
Olhar o celular a cada 5 minutos.
✓ Faça
Aprove o plano e deixe trabalhar.
/remote-control
08

Navegador embutido

O Claude usa sites como você, mesmo sem integração.

O app tem um navegador próprio. Você entra na sua conta uma vez, e o Claude lê páginas e clica por você. Serve para painéis e sites que não têm outra forma de automatizar.

Como usar

  1. Abra com Cmd + Shift + B (Windows: Ctrl + Shift + B).
  2. Faça o login você mesmo.
  3. Peça o trabalho em palavras.

Segurança

Mantenha o app atualizado e peça sempre "não publique nem altere nada" quando for só leitura.

✕ Evite
Abrir sites desconhecidos com o app desatualizado.
✓ Faça
Atualize o app antes.
Abra no navegador o painel do meu canal no YouTube. Já estou logado.
Ache o vídeo mais recente e leia a página dele.
Faça 5 ideias de cortes com a minutagem, uma descrição nova e um post para a comunidade.
Não publique nem altere nada no site.
09

Slides, designs e painéis

Diga o que quer, veja pronto, ajuste em palavras.

No Claude (aba Chat do app ou claude.ai) você pede uma apresentação, uma arte ou um painel de números e ele monta na conversa. Os nomes oficiais são Claude Slides, Claude Design, Dashboards e Claude Motion (vídeo animado). Você ajusta falando, sem abrir outro programa.

Como usar

  1. Peça a peça em palavras.
  2. Ajuste em palavras ("letra maior", "tire o slide 4").
  3. Compartilhe o link.

Números

Antes de mostrar um painel, confira 3 números com a fonte original.

✕ Evite
Compartilhar um painel sem conferir.
✓ Faça
Confira 3 números com a fonte.
Slides e Design valem em todos os planos. Dashboards está em beta. O Claude Motion está em beta e só nos planos Team e Enterprise.
Faça uma apresentação de 7 slides resumindo a aula 1 (aula-1/roteiro.md).
Uma ideia por slide, letras grandes, preto e amarelo.
A melhor frase da aula vai no slide 1.
10

Docs compartilhados

Uma página viva que a equipe usa junto com o Claude.

No Claude (aba Chat do app ou claude.ai), ele cria um documento (Claude Docs) que você compartilha por link. Quem recebe pode ver, comentar ou editar, conforme a permissão que você der. Você (dono do doc) marca @Claude num comentário e ele revisa ou responde ali mesmo.

Como usar

  1. Peça o documento.
  2. Compartilhe e escolha: ver, comentar ou editar.
  3. Você marca @Claude num comentário para ele agir.

Por que não um arquivo?

A página fica viva. Todo mundo mexe na mesma cópia, sem versões perdidas no e-mail.

✕ Evite
Mandar arquivos de um lado para o outro.
✓ Faça
Uma página só, que a equipe edita.
Crie um doc para controlar os convidados das lives deste mês.
Uma tabela com: nome, tema, data e situação (convidado, confirmado, gravado).
Deixe pronto para eu compartilhar com a equipe.
11

Comandos de barra

Atalhos curtos que mudam como o Claude trabalha.

Digite / na caixa de mensagem de uma sessão da aba Code e escolha um comando da lista. Não precisa programar. Estes cinco já ajudam muito no dia a dia.

Como usar

  1. Digite /.
  2. Escolha o comando.
  3. Comece por /output-style concise: as respostas ficam mais curtas. Para voltar, rode /output-style de novo e escolha outro estilo.

Comando seu não aparece?

Se você criou uma skill, deixe a descrição curta e diga quando usar.

  • /rewind: volta para antes de uma resposta ruim (ou aperte Esc duas vezes).
  • /context: mostra o que está ocupando a conversa.
  • /recap: resumo de uma linha quando você volta de uma pausa.
  • /goal: segue trabalhando até uma meta clara.
  • /output-style: respostas mais curtas ou mais explicadas.
✕ Evite
Descrição longa e vaga nas suas skills.
✓ Faça
Curta, dizendo quando usar.
/output-style concise
12

Mods

Mude a cara e o jeito do Claude Code: faixas, avisos, barras e comandos.

Um mod é um complemento que muda como o Claude Code aparece e se comporta. Pode mostrar uma barra de quanto da conversa já foi usada, um aviso quando algo termina ou um comando novo. Você não precisa mexer no código: pede ao Claude para conferir e instalar, ou para criar um.

Como usar

  1. Atualize para a versão 2.1.287 ou mais nova.
  2. Numa sessão da aba Code, cole o prompt abaixo com o link do mod.
  3. Ou peça para o Claude criar um mod para você.

Exemplos prontos

18 mods prontos e testados (em português): inematds/inema-mods.

✕ Evite
Instalar mod sem ler o que ele faz.
✓ Faça
Peça ao Claude para conferir o código antes.
Mods não rodam isolados: têm acesso ao que o Claude Code acessa. Por isso o prompt pede ao Claude para conferir antes. Para quem usa o terminal: claude plugin validate seguido da pasta do mod lista o que ele pede, e claude --safe-mode abre o Claude Code sem nenhum mod.
Quero instalar este mod do Claude Code: [cole o link do GitHub]
Antes de instalar, leia o código e rode claude plugin validate na pasta dele.
Me diga em palavras simples o que ele pode acessar: meus arquivos, comandos, a internet.
Se estiver seguro, instale e me diga como desligar.
Sem link? Então crie um mod pequeno: [diga o que quer ver, ex.: uma barra mostrando quanto da conversa já foi usado].
13

Claude Duet

Um ajudante que traz o trabalho até você.

O Duet olha o que está pendente nos seus projetos, prepara o rascunho do trabalho e pergunta antes de agir. Em vez de você lembrar de tudo, ele traz a próxima tarefa.

Como usar

  1. Acesse claude.com/product/claude-duet.
  2. Entre na lista de espera.
  3. Quando liberar, peça a tarefa do dia.

Para que serve

Manter os projetos andando quando você não está olhando.

✕ Evite
Usar para tarefas soltas do dia a dia.
✓ Faça
Use para manter os projetos andando.
Hoje só nos EUA, em prévia, com lista de espera (planos Pro, Max e Ultra). No Brasil ainda não está disponível: guarde o prompt para quando chegar.
Toda manhã, olhe o meu trabalho do curso e do canal no Claude.
Me traga a tarefa que mais vai poupar tempo hoje.
Faça o rascunho e me pergunte antes de enviar, publicar ou apagar qualquer coisa.
